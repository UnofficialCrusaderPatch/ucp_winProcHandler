# winProcHandler

**نویسنده**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

این ماژول به کد ماژول‌های دیگر اجازه می‌دهد یک تابع WindowProc تغییریافته ثبت کنند. به این ترتیب می‌توان زنجیره‌ای از توابع را میان پیام‌های ورودی پنجره و تابع WindowProc اصلی Crusader قرار داد.

این افزونه زیربنایی است و قابلیت مستقیمی برای استفاده در بازی ارائه نمی‌کند. برای اطلاعات بیشتر، README مخزن را بخوانید.
