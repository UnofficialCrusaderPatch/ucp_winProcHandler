# winProcHandler

**Autor**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Dieses Modul ermöglicht es anderem Modulcode, eine angepasste WindowProc-Funktion zu registrieren. So lassen sich Funktionen zwischen eingehende Fensternachrichten und die ursprüngliche WindowProc-Funktion von Crusader schalten.

Es handelt sich um eine technische Grundlage ohne direkt nutzbare Spielfunktionen. Weitere Informationen stehen in der README des Repositorys.
