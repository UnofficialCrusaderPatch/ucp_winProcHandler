# winProcHandler

**Yazar**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Bu modül, diğer modüllerin kodundan değiştirilmiş bir WindowProc işlevi kaydetmeyi sağlar. Böylece gelen pencere iletileri ile Crusader’ın özgün WindowProc işlevi arasına işlevler zinciri yerleştirilebilir.

Doğrudan kullanılabilir oyun özellikleri sunmayan, alt düzey bir uzantıdır. Daha fazla bilgi için deponun README dosyasına bakın.
