# winProcHandler

**Auteur**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Ce module permet au code d’autres modules d’enregistrer une fonction WindowProc personnalisée. Des fonctions peuvent ainsi être intercalées entre les messages entrants de la fenêtre et la fonction WindowProc d’origine de Crusader.

Il s’agit d’une extension technique sans fonctionnalité directement utilisable dans le jeu. Consultez le fichier README du dépôt pour en savoir plus.
