# winProcHandler

**Autor**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Este módulo permite que el código de otros módulos registre una función WindowProc modificada. Así se pueden encadenar funciones entre los mensajes entrantes de la ventana y la función WindowProc original de Crusader.

Es una extensión de bajo nivel que no ofrece funciones de juego directamente utilizables. Consulta el README del repositorio para más información.
