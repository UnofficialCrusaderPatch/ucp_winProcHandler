# winProcHandler

**Автор**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Этот модуль позволяет коду других модулей регистрировать изменённую функцию WindowProc. Так можно выстроить цепочку функций между входящими сообщениями окна и исходной функцией WindowProc в Crusader.

Это низкоуровневое расширение, которое не предоставляет игровых возможностей для непосредственного использования. Подробнее см. README репозитория.
