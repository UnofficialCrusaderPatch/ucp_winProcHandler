# winProcHandler

**Szerző**: [TheRedDaemon](https://github.com/TheRedDaemon/ucp_winProcHandler)

Ez a modul lehetővé teszi, hogy más modulok kódja módosított WindowProc függvényt regisztráljon. Így függvények illeszthetők a beérkező ablaküzenetek és a Crusader eredeti WindowProc függvénye közé.

Ez egy alacsony szintű bővítmény, közvetlenül használható játékfunkciók nélkül. További információ a forráskódtár README fájljában található.
